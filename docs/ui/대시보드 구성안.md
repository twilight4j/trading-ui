# 한국 주식시장 상태판 대시보드 구성안

목표:
“오늘 시장이 매매하기 좋은 장인지”를 한눈에 판단하는 대시보드

추천 방식:

* 상단 = 시장 전체 위험도
* 중단 = 수급/시장폭
* 하단 = 테마·단타 분위기

---

# 1. 최상단: 시장 상태 요약 (핵심)

가장 중요한 영역입니다.

## 표시 항목

| 항목       | 의미      | 기준 예시         |
| -------- | ------- | ------------- |
| 코스피 등락률  | 대형주 분위기 | +1% 이상 강세     |
| 코스닥 등락률  | 개별주 분위기 | 코스닥 강하면 단타 유리 |
| 시장 상태 점수 | 종합 점수   | 0~100         |
| 시장 상태 라벨 | 직관적 상태  | 강세 / 중립 / 위험  |

---

## 추천 UI

예시:

```text
시장 상태: 강세 🔥
시장 점수: 78 / 100

KOSPI   +1.24%
KOSDAQ  +2.11%
```

---

## 핵심 계산

### 상승 비율



---

## 해석 기준

| 상태          | 의미      |

# 3. 외국인·기관 수급 영역

한국 시장 핵심

## 표시 항목

| 항목         | 중요도   |
| ---------- | ----- |
| 외국인 현물 순매수 | 높음    |
| 외국인 선물 순매수 | 매우 높음 |
| 기관 순매수     | 중간    |
| 프로그램 매매    | 높음    |

---

## 추천 강조

특히 이것 강조:

```text
외국인 선물
+4,200억  ← 강세 시그널
```

---

## 상태 판단 예시

| 조건               | 해석       |
| ---------------- | -------- |
| 외국인 현물+선물 동시 순매수 | 매우 긍정    |
| 선물 대량 매도         | 위험       |
| 프로그램 매수 유입       | 지수 상승 가능 |

# 8. 최종 시장 점수 시스템 (추천)

실전용으로 매우 유용

## 예시 점수 구조

| 항목        | 배점 |
| --------- | -- |
| 코스닥 상승    | 20 |
| 상승종목 우세   | 20 |
| 외국인 선물 매수 | 20 |
| 거래대금 증가   | 15 |
| 주도주 강세    | 15 |
| 환율 안정     | 10 |

총점:
100점

---

## 상태 기준

| 점수     | 상태      |
| ------ | ------- |
| 80~100 | 매우 강한 장 |
| 60~79  | 양호      |
| 40~59  | 애매      |
| 20~39  | 위험      |
| 0~19   | 매우 위험   |
