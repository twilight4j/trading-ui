# 트레이딩 대시보드

## 요구사항

1. 계좌별 전략설정
아래 내용은 반드시 포함
- 종목에 진입할 조건식 설정
- 매수한 후 매도/매수 규칙 설정
2. 계좌별 대시보드
- 대시보드에 어울리는 정보들로 구성
- KODEX 200(069500) 와 비교하여 성과분석

## 지침
- 요구사항들은 필수적인 내용들을 생각나는 대로 떠올린 것이며 유용하고 좋은 아이디어가 있다면 언제든 환영.
- 필요한 API 가 있다면 만들어 줄 수 있으니 가지고 있는 API들 만으로 무리하게 구현하지 않을 것.
- 계좌별 전략설정의 자세한 아키텍처를 아래 문서를 참고
  * `settings_app_react_requirements.md`
