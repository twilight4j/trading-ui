네, **전략설정 API는 거의 충분**하고,  
**통합대시보드는 몇 개가 부족**합니다.

현재 있는 것(활용 가능):
- 계좌 목록: `GET /api/v1/strategies/accounts`
- 계좌별 보유/손익 스냅샷: `POST /api/v1/stk/acnt/profit-rate`
- 주문/체결: `POST /api/v1/stk/acnt/cntr`, `POST /api/v1/stk/acnt/cntr/detail`
- 벤치마크 가격 데이터: `POST /api/v1/stk/chart/daily` (KODEX 200 시계열용)
- 계좌 활성 전환: `POST /api/v1/auth/active`

부족한 것(통합대시보드 관점 핵심):
- **통합 집계 API**: 여러 계좌를 합산한 자산/손익/수익률을 한 번에 주는 API가 없음
- **성과 비교용 시계열 API**:  
  통합 + 계좌별 + KODEX를 같은 기준(기간/정규화)으로 내려주는 API가 없음
- **멀티 계좌 배치 조회 API**:  
  지금은 계좌마다 `auth/active` 전환 후 호출해야 해서 비효율/레이스 위험이 있음
- (선택) **요약 KPI API**: MTD/YTD, 최대낙폭(MDD), 변동성 등 대시보드용 요약 지표 API 부재

실무적으로는 아래 2개만 추가해도 대시보드가 깔끔해집니다:
1) `GET /api/v1/dashboard/summary?account_ids=...`  
2) `GET /api/v1/dashboard/performance?account_ids=...&benchmark=069500&period=YTD`

원하면 제가 바로 이 두 API의 **응답 스키마(JSON)**까지 제안해드릴게요.
